# NPC State Delta 1.0.20 deterministic time-compressed-development review

## Scope

Delta 1.0.20 fixes the remaining durable-development false negative where a provider can correctly describe a long-term Personality/Speech transition but label it `gradual`/`refine` or `gradual`/`keep`, preventing the existing batch/time-skip exception from running. The fix is deterministic and field-general. It adds no model request, no background worker, no prompt expansion, and no persisted schema change.

## Architecture

- The existing development-scale gate remains the authority for explicit/batch evidence, but its readiness predicate is now reusable by the facade after provider output is normalized.
- The facade independently re-evaluates batch readiness only for `gradual` or `batch` Personality/Speech candidates. It requires a changed candidate, an elapsed span in the supplied development context, sustained development inside the time-skip window, and a development reason grounded to that same context.
- Named seasons and seasonal ranges are recognized alongside ordinary elapsed day/week/month/year/season spans. Sustained-development vocabulary covers learning, practice, training, study, apprenticeship, progression, improvement and mastery.
- A candidate that reaches this recovery path must still pass field-specific deterministic candidate grounding against supplied profile evidence and development context. Personality's protected morality safety remains part of that grounding. Manual field locks are checked before this path.
- Bare time passage remains non-destructive. The normal v1.0.19 three-independent-observation gradual ledger remains unchanged when no grounded elapsed-development window exists.

## Regression coverage

The focused ledger suite now includes the reported shape directly: stale developing/non-verbal Speech, two lexically different later observations, a provider-supplied polished current Speech candidate, `speechState: refine`, `developmentScale: gradual`, and a spring-to-summer academics/apprenticeship/social-mimicry development interval. The candidate is accepted through deterministic batch recovery without requiring three ordinary post-skip observations.

Additional coverage proves that seasonal passage by itself cannot bypass gradual evidence and that the same elapsed-development recovery applies to Personality rather than being hard-coded to Speech or a named NPC.
